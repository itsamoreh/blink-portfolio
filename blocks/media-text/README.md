# Media and Text Block

This block allows you to display an image on the left side with text content on the right side.

## Features

- Image upload functionality
- Rich text editing for content
- Responsive design

## Usage

1. Add the "Media and Text" block to your post or page.
2. Click on the left side to upload an image or select one from the media library.
3. Enter your text content on the right side using the rich text editor.

## Customization

You can customize the block's appearance by modifying the `style.css` file. The block uses WordPress theme variables for consistent styling across your site.

## Development

To modify this block:

1. Edit `edit.js` to change the editor component.
2. Modify `media-text.php` to adjust the frontend rendering.
3. Update `block.json` to change block settings or add new attributes.
4. Adjust styles in `style.css` as needed.

Remember to rebuild your assets after making changes to JavaScript or CSS files.
